ディスクの扱い

自分のイメージは「ディスクを追加」で登録してください。ブラウザの IndexedDB に 保存されるのでリロードしても消えません。下の一覧で FDD1 / FDD2 / SCSI0 / SCSI1 を 選び、「この構成で再起動」でそのディスクから起動します。実行中の入れ替えは F11 のメニューからもできます（登録済みイメージは全部 /disk に置かれています）。

「HDDイメージ作成」は PC-98 の領域確保と FAT16 フォーマットまで 済んだ SCSI イメージ（最大 100MB、.hdn 形式）を作ります。 BTNPART や FORMAT を実行する必要はなく、再起動すればすぐ C: として使えます。

ゲスト側の書き込みは MEMFS 上にしか無いので、リロードで失われます。 残したいときは各行の 保存 でライブラリに書き戻すか、 DL でイメージをダウンロードしてください。 ファイルはブラウザの中だけに置かれ、どこにも送信されません。

ホストでコードを書いてエミュレータでコンパイルする

  1. 「ディスクの中身」で lsic_98.xdf を開く
  2. 「ファイルを入れる」で手元の .c を入れて「保存」
  3. ディスク一覧で fd98_2hd.img を FDD1、lsic_98.xdf を FDD2 にして「この構成で再起動」
  4. B: のあと \LSIC86\BIN\LCC 自分のファイル.C でコンパイル
  5. できた .EXE は「ディスクの中身」の「取り出す」でホストに戻せます

「ディスクの中身」はエミュレータとは別の wasm（pc98fat.wasm、26KB）で動いていて、 ライブラリ側のイメージだけを触ります。実行中のディスクに書いた内容を見たいときは、 先にディスク一覧側の「保存」を押してください。編集結果は「この構成で再起動」で反映されます。 エディタが要るときは vz_98.xdf の VZ Editor を使ってください。

BIOS ROM について

NP2kai は ITF ROM を内蔵しているので、実機の BIOS ROM なしで動きます。 漢字表示用の font.rom は東雲フォントから作ったものを同梱しています（パブリックドメイン相当）。 sound.rom（PC-9801-26K/86 のサウンド BIOS）と 2608_*.wav （OPNA リズム音源）を入れると音の再現が上がりますが、こちらは著作権物のため 含まれていません。
